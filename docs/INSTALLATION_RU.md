# Установка прошивки

## Что потребуется

- Freenove FNK0104S;
- кабель USB с передачей данных;
- microSD, отформатированная в FAT32;
- Arduino IDE 2.x;
- пакет плат ESP32 by Espressif Systems 3.2.0;
- библиотеки для FNK0104S из официального комплекта Freenove.

## Настройки Arduino IDE

```text
Board: ESP32S3 Dev Module
USB CDC On Boot: Enabled
USB Mode: Hardware CDC and JTAG
Upload Mode: UART0 / Hardware CDC
Flash Size: 16MB
PSRAM: OPI PSRAM
```

Для дисплея должна использоваться конфигурация FNK0104S с ST7796,
разрешением 320×480 и сенсором FT6336U.

## Загрузка

1. Распакуйте архив проекта.
2. Откройте одноимённый файл `.ino` в папке прошивки.
3. Подключите FNK0104S и выберите её COM-порт.
4. Проверьте настройки платы.
5. Нажмите Verify, затем Upload.
6. Откройте Serial Monitor на скорости 115200.

После запуска на экране должна отображаться версия `v0.15.4` и четыре цвета
бактерий. Команда `sd status` показывает состояние карты памяти.

## Проверка записи

1. Нажмите `REC`.
2. Подождите 10–20 секунд.
3. Нажмите `STOP`.
4. Извлеките карту после завершения записи.
5. Откройте `universe_NNN.csv` в Bacteria Universe Replay.

Если карта не подключилась, симуляция продолжит работать без записи. Проверьте
посадку карты, FAT32 и перезапустите плату.
