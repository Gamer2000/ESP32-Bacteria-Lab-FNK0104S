# Формат universe_NNN.csv

Файл содержит полные последовательные кадры мира. Поле `frame` задаёт порядок,
а `seconds` — время симуляции. В v0.15.4 кадры записываются раз в секунду.

## Типы строк

- `settings` — режимы данного кадра;
- `bacterium` — живая бактерия;
- `biomass` — остаточная биомасса погибшей бактерии.

## Основные поля

| Поле | Значение |
|---|---|
| frame | номер кадра |
| seconds | время мира в секундах |
| object_type | тип строки |
| id | уникальный ID бактерии |
| parent_id | ID родителя |
| lineage_id | родословная |
| species | Explorer, Sprinter, Survivor или Breeder |
| generation | поколение |
| x, y | координаты |
| energy | энергия |
| age | возраст |
| death_cause | ENERGY, AGE, KIA или TOXIN |
| death_second | время гибели |
| radius | размер при записи или гибели |

Геном записывается отдельными числовыми полями: скорость, радиус сенсора,
метаболизм, порог размножения, максимальный возраст, склонность к кувырку,
агрессивность, параметры питания остаточной биомассой и устойчивость к яду.

В строке `settings` поля `war`, `poison`, `carrion`, `mutation`, `food_auto`
и `simulation` показывают условия именно этого кадра.
